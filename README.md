## Projects

### PXLNET Connect

Android VPN client based on **sing-box** for the PXLNET service.

Supports VLESS, Hysteria2, smart routing, server monitoring, subscriptions, diagnostics and PXLNET integration.

**Android · Kotlin · Networking · VPN**

[Repository](https://github.com/kakixc/PXLNET-Connect)

---

### PXL Meshtastic Firmware

Custom Meshtastic firmware builds with PXL UI improvements while keeping compatibility with the normal Meshtastic network.

Includes custom boot/status screens, Cyrillic OLED support and automated multi-board builds.

**C++ · ESP32 · LoRa · GitHub Actions**

[Repository](https://github.com/kakixc/pxl-meshtastic-firmware)

### PXL Cone Launcher

A planned Minecraft launcher based on **PineconeMC**.

The goal is to keep the power of Prism/Pinecone while improving everyday UX, instance sharing, migration and cross-platform workflows.

**C++ · Qt · Minecraft**

> Coming soon.

[Repository](https://github.com/kakixc/PXL-Cone-Launcher)

Arduino-based automatic watering system with soil moisture monitoring, water-level protection, temperature/humidity monitoring and an LCD interface.

**Arduino · C++ · Hardware**

## Проекты

### PXLNET Connect

Android VPN-клиент на базе **sing-box** для сервиса PXLNET.

Поддерживает VLESS, Hysteria2, Smart Routing, мониторинг серверов, подписки, диагностику и интеграцию с PXLNET.

### PXL Meshtastic Firmware

Сборки Meshtastic с небольшими изменениями интерфейса PXL без нарушения совместимости с обычной сетью Meshtastic.

Есть собственные boot/status-экраны, поддержка кириллицы на OLED и автоматические сборки под несколько устройств.

**C++ · ESP32 · LoRa · GitHub Actions**

[Репозиторий](https://github.com/kakixc/pxl-meshtastic-firmware)

---

### PXL Cone Launcher

Планируемый Minecraft-лаунчер на базе **PineconeMC**.

**C++ · Qt · Minecraft**

> Скоро.

[Репозиторий](https://github.com/kakixc/PXL-Cone-Launcher)
